# Falcon Finalysis reliability audit — 07/10/2026

This release repairs confirmed defects across calculations, exchange adapters, document intake,
workspace storage, exports and browser workflows. It does not certify that every possible input,
device, exchange layout or production failure has been covered.

## Repairs and their effect

| Area | Confirmed issue and resulting behavior |
|---|---|
| Portfolio calculations | Ticker/weight names align after normalization; returns use common price boundaries; empty period bins stay missing; drawdown includes initial capital; Sharpe/Sortino and the opportunity set use a consistent periodic risk-free target. |
| Valuation | Finite assumptions and valid growth bounds are enforced; invalid sensitivity cells stay blank; ROIC uses average invested capital; reinvestment excludes cash and financing working capital; shares and FCFF require explicit source review. |
| CredGrid | Invalid rows block calculation. Missing calendar months withhold the score/proposal. Reviewed financing/transfer receipts are excluded; debt service is counted once. Missing evidence and unverified revenue categories are disclosed. Model version is CG-CF-1.2. |
| Exchange facts | Requested DSE/CSE identities are checked. CSE profile fields exclude shareholding/director/rating table headers. Cash and stock dividends remain distinct, including CSE's %C/%B markers. |
| Prices | Official responses are bounded; rows are finite, dated, ordered and limited to the requested period. Multi-ticker uploads are explicitly supported by the portfolio importer. Loaded source, dates and market context remain visible. |
| Spreadsheet intake | Full-cell numeric parsing preserves scientific notation and rejects malformed prefixes/grouping. Duplicate headers, formulas, excessive dimensions/rows and expanded ZIP size block import. |
| Statement extraction | Label matching avoids current/non-current and cash/cash-flow confusion; multiple statement sections are read; conflicting values require review. PDF/workbook bounds are enforced. |
| Source references | Reviewed corrections and manual additions are labeled distinctly from original extracted values. Scaling is recorded; obsolete references are removed when values or years are removed. |
| Editor and result state | Changed inputs invalidate valuation, portfolio and credit results/exports. New workspaces reset holding edits and review confirmations. Comparison selection changes remove previous companies. |
| Human review | Credit consent gates extraction/calculation. Withdrawing consent removes results/exports. Decision submission validates confirmation on the server and requires the current saved inputs. |
| Storage and recovery | SQLite connections close after commit/rollback. Backups include committed WAL data and refuse nonexistent sources. Recovery rejects ambiguous/malformed JSON and conflicting provenance. Account flags fail closed; expiry and redirected workspace paths are checked. |
| Exports | Excel metadata and headers cannot inject formulas; missing volume stays missing; UTC dates convert correctly; illegal control characters are removed. PDF source rows paginate rather than breaking long references. |
| Usability | Three starting tasks and a working complete-demo button simplify the home page. Dark-mode menus, captions, help icons and chart colors are readable; keyboard focus and reduced-motion preferences are supported. The selected concept-C logo is preserved. |

  26 prices each for 01/09/2026–06/10/2026.
- Official CSE check: verified SQURPHARMA identity and cash-dividend markers; five annual years

Live checks establish behavior at the time tested. They do not guarantee continued exchange access.
The public deployment has its own dependency/runtime checks; local success alone is not proof of deployment.

## Work that still requires external configuration or validation

1. **Permanent private accounts:** choose a sign-in provider and persistent hosting, then configure
   trusted authentication, encrypted storage, retention and scheduled backups. Setup is prepared;
   the existing public demo remains temporary session storage. See ACCOUNT_SETUP.md.
2. **Commercial credit use:** validate CredGrid against representative repayment outcomes and
   complete lender/product policy review. A transparent cash-flow pilot is not a validated credit score.
3. **Market continuity:** exchange layouts/access can change. Production service reliability needs
   approved data access, coverage monitoring and operational ownership.
4. **Further assurance:** multi-user load testing, wider browsers/devices and independent financial
   review remain separate work. Annualization uses conventional factors; portfolio estimates are historical.
